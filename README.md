# The School of Jazz Website

Static prototype for the School of Jazz charity website.

Published at:

```text
http://theschoolofjazz.com
```

## Open Locally

Run from this folder:

```sh
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Notes

- The public side introduces the mission and links to the Summer Book.
- The practice portal uses browser `localStorage` for demo student logs.
- The teacher view summarizes student streaks, minutes, and logs.
- The inspiration library links to searchable performance references.
